# Ekran Görüntüleri

Uygulama ekran görüntülerini bu klasöre aşağıdaki adlarla koy — site otomatik gösterir.
Dosya yoksa ilgili karede "EKRAN GÖRÜNTÜSÜ YAKINDA" yer tutucusu görünür.

| Dosya | Özellik karesi |
|---|---|
| `kare-01.png` | Film & Dizi Takibi |
| `kare-02.png` | Sosyal Akış |
| `kare-03.png` | Sahne Tahmin Oyunu |
| `kare-04.png` | AI Film Önerisi |
| `kare-05.png` | İstatistik & Wrapped |
| `kare-06.png` | Grup Sohbetleri |
| `kare-07.png` | Aylık Turnuvalar |
| `kare-08.png` | Hatırlatıcı & Takvim |

Öneri: dikey telefon ekran görüntüsü (9:19 civarı). Görsel üstten hizalanıp
kırpılır (`object-fit: cover; object-position: top`), yani ekranın üst kısmı görünür.
PNG yerine JPG kullanacaksan `index.html` içindeki `src`/`data-file` uzantılarını değiştir.
