 ADIM 8 ★  Firestore Security Rules Sıkılaştır
 Risk: ÇOK DÜŞÜK  |  Kazanç: GÜVENLİK  |  Süre: ~3 saat
──────────────────────────────────────────────────────────────────────────────

NEDEN:
  Subcollection yapısına geçince security rules da güncellenmeli.
  Aksi halde başka kullanıcılar birbirinin listelerini yazabilir.

ÖNERİLEN RULES PATTERN:
  rules_version = '2';
  service cloud.firestore {
    match /databases/{database}/documents {

      match /Lists/{uid}/{document=**} {
        allow read: if request.auth != null;         // arkadaşlar okuyabilir
        allow write: if request.auth.uid == uid;     // sadece sahibi yazabilir
      }

      match /Users/{uid} {
        allow read: if request.auth != null;
        allow write: if request.auth.uid == uid;
      }

      match /Notes/{uid}/{document=**} {
        allow read, write: if request.auth.uid == uid;
      }

      match /Reminders/{uid}/{document=**} {
        allow read, write: if request.auth.uid == uid;
      }

      match /MovieComment/{movieId}/comments/{commentId} {
        allow read: if request.auth != null;
        allow create: if request.auth != null;
        allow update, delete: if request.auth.uid == resource.data.userId;
      }
    }
  }

ADIMLAR:
  1. Firebase Console → Firestore → Rules sekmesine git.
  2. Yukarıdaki rules'ı uygula ve Rules Playground ile test et.
  3. Her yeni subcollection için ilgili rule'ı ekle.


──────────────────────────────────────────────────────────────────────────────
 MİGRASYON STRATEJİSİ (TÜM ADIMLAR İÇİN)
──────────────────────────────────────────────────────────────────────────────

Canlı uygulamada veri kaybı yaşamamak için önerilen yaklaşım:

  AŞAMA 1 — Çift Yazma (Dual Write)
    Yeni kod hem eski hem yeni yapıya yazar.
    Uygulama eski yapıdan okur. Veri kaybı riski sıfır.

  AŞAMA 2 — Migration
    Arka planda (veya toplu script ile) eski veriyi yeni yapıya kopyala.
    Firestore batch write kullan (500 döküman/batch limiti var).

  AŞAMA 3 — Okuma Geçişi
    Yeni kod yeni yapıdan okumaya başlar. Eski yapı hâlâ duruyor.
    Test et, sorun yoksa devam et.
